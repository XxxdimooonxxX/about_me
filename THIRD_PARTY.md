## Project-created assets

Room geometry, mechanical assemblies, signage, ceramic panel maps, foliage, moss masks, and the scene poster are created for this project in src/chamber.js. The scene uses the user's reference as art direction. No Valve game files or extracted game models are redistributed. Portal and Aperture references are fan-inspired design elements; this project is not affiliated with Valve.
